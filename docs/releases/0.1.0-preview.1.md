First Android preview for AirPods Pro 3, targeting Pixel 9.

- Expo and HeroUI Native interface with rounded Material You controls.
- System, light, and dark themes; Android 12+ wallpaper colors.
- Listen, Controls, and Settings screens.
- Native paired-device list, Bluetooth settings, and Android media volume.

The app starts in a clearly labeled preview with sample battery values. Listening-mode buttons and automation switches in preview change the interface only. Live mode does not yet send AirPods-specific commands or read individual battery levels. Siri, Find My, Apple Live Translation, firmware updates, and hearing-health features are not implemented.

Install the APK on your Android phone. No Expo Go or development server is required. Android will ask you to allow installation from your browser or file manager. Nearby devices access is requested only when you tap Connect.

Advanced AirPods support will need a native protocol implementation and physical AirPods Pro 3 validation. Pixel OS and Bluetooth stack versions affect compatibility.
