This standalone preview updates listening controls, the Android volume slider, and battery refresh behavior. Install the APK over the existing app; Expo Go and a preview server are not required.

- Listening mode is a single three-way segmented selector. Compatible models show Transparency, Adaptive, and Noise cancellation, with a noise-control on/off switch underneath. Older models use Transparency, Off, and Noise cancellation. The displayed selection still comes from the AirPods response.
- Android media volume uses the native Material 3 slider through Expo UI, with the app’s wallpaper colors and light/dark appearance. Its drag value is kept separate from incoming volume polls to prevent jumps during interaction.
- Percentage and charging status are tracked independently. Charging reports remain usable when the percentage is unavailable, and unknown updates no longer erase a previously reported charging state. Old values are explicitly labeled as last reported.
- AirPods notification requests repeat every 15 seconds, with another refresh when returning to the app. Manual refresh waits for a battery report instead of returning immediately after sending a request. A timeout reports that no new reading arrived.
- Battery readings show their update age, and data older than 45 seconds is marked stale.

Case charging and battery changes require a report from the hardware. A closed or sleeping case may not report immediately. Physical AirPods validation of these changes is pending.

Settings includes a Share battery report action for diagnosing charging behavior on real hardware. Reports contain only the model, battery fields, timestamps, and a bounded history of battery percentage/status codes, with no device name, Bluetooth address, or serial number. Reports are shared only when you choose that action.

Pre-build validation: AirPods native module compilation, 17 native regression tests, four model/segmented-control tests, lint, TypeScript, and all 20 Expo Doctor checks passed. Interactive and physical AirPods validation remains pending.
